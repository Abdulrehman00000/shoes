# 👞 Atelier Vendôme — Haute Cordonnerie & Luxury Footwear

An elite, high-fashion luxury footwear e-commerce experience celebrating bespoke shoemaking, hand-burnished patinas, and Parisian craftsmanship.

Built with **React 19**, **TypeScript**, **Tailwind CSS 4**, and **Framer Motion**.

---

## ✨ Key Features

- **🎨 Interactive Patina & Colorway Engine**: Click on any leather swatch to dynamically update shoe models with instant visual switching.
- **🔍 3D Angle Showcase**: Multi-perspective product viewer with angle rotation, sole inspection, and artisanal detail inspection.
- **🪡 Bespoke Studio Customizer**:
  - Leather selection (French Box Calf, Museum Patina, Tuscan Pebble, Exotic Nile Croc).
  - Sole architecture (Baker Oak Bark Leather, Beveled Waist, Vibram Concealed Island).
  - Custom engraved 3-letter gold monograms.
- **💱 Global Sovereign Multi-Currency Suite**:
  - Live conversions for 25+ sovereign currencies (USD, EUR, GBP, PKR, AED, SAR, INR, CAD, AUD, CHF, JPY, and more).
  - Real-time search filter by country name, currency code, or symbol.
- **🛍️ Luxury Shopping Bag & Drawer**:
  - Preserves selected leather colorway, shoe size, and bespoke monogramming.
  - Smooth slide-out cart drawer with responsive layout and live order subtotal.
- **⭐ Curated Collection**:
  - The Vendôme Wholecut Oxford
  - The Medici Double Monk Strap
  - The Riviera Crocodile Tassel Loafer
  - The Saint-Germain Split-Toe Derby
  - The Kensington Wholecut Chelsea Boot
  - The Vendôme Belgian Slipper
- **💎 VIP Concierge & Heritage Experience**: Interactive size guide, shoe care masterclass, and provenance certificate generator.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Audio Feedback**: Web Audio API Soundscapes

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18+) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Abdulrehman00000/shoes.git
   cd shoes
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the boutique.
